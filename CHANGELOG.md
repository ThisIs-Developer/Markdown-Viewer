**Title:** fix(desktop): open file passed as CLI argument on launch

**Description:** When a .md file is set to open with the desktop app (e.g. via OS file
association), the file path is passed as a command-line argument.
Previously the app ignored it and always showed the landing page,
requiring the user to drag-and-drop or import the file manually.

This change reads the argument in main.js using Neutralino.filesystem
.readFile and injects the content into the editor on startup.
filesystem.readFile is also added to nativeAllowList in
neutralino.config.json to permit the API call.
